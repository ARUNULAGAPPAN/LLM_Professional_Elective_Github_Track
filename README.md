## 📌 Repository Overview

This repository is maintained as part of the **LLM Professional Elective course** to demonstrate **hands-on learning, implementation skills, and conceptual understanding** of Large Language Models.

The repository contains a **series of mini-sized, well-documented projects** focused on:
- Core LLM concepts
- Transformer-based models
- Real-world NLP applications
- Ethical and practical considerations of LLMs

Each project is **self-contained**, **incrementally developed**, and **academically aligned** with the course syllabus.

---

## 🎯 Objectives

- Understand the **working principles of LLMs**
- Implement **mini projects** using pre-trained transformer models
- Apply LLMs to **real-world NLP tasks**
- Gain experience in **prompt engineering, fine-tuning, and evaluation**
- Maintain **professional GitHub practices** (clean code, documentation, commit history)
