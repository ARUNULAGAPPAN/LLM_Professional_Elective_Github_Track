## 📖 Project Overview
This project is a real-world implementation of a **Sequence-to-Sequence (Seq2Seq)** Artificial Intelligence model designed to correct grammatical errors, fix spelling mistakes, and improve sentence structure. 

Unlike standard spell-checkers that only look at individual words, this tool uses a **Large Language Model (LLM)** based on the **T5 (Text-to-Text Transfer Transformer)** architecture to understand the *context* of the sentence and generate fluent English text.

### 🚀 Key Features
*   **Context-Aware Correction:** Fixes errors like subject-verb agreement (e.g., *"He go"* → *"He goes"*).
*   **Spelling & Punctuation:** Automatically corrects misspellings and capitalizes sentences.
*   **Interactive UI:** Built with **Gradio** to provide a user-friendly web interface directly in the browser.
*   **Cloud-Powered:** Runs entirely on Google Colab using free GPU resources.

## ⚙️ How It Works (The Logic)

1.  **Input Processing:** The user inputs text (e.g., *"Me is happy"*).
2.  **Tokenization:** The text is converted into numerical IDs that the AI understands.
3.  **Inference:** The **T5 Model** (Pre-trained on millions of sentences) predicts the most likely correct sequence of words.
4.  **Decoding:** The numbers are converted back into human-readable text (e.g., *"I am happy"*).
5.  **Output:** The corrected sentence is displayed in the Gradio Interface.

## 💻 Code Snippet

Here is the core logic used to correct the grammar:

```python
from transformers import pipeline

# Load the pipeline
corrector = pipeline("text2text-generation", "pszemraj/flan-t5-large-grammar-synthesis")

def fix_text(text):
    # Generate the corrected text
    results = corrector(text, max_length=512)
    return results[0]['generated_text']

# Example
print(fix_text("he run fast")) 
# Output: He ran fast.
